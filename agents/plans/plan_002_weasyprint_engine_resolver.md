## 1. 🎯 Цель и контекст
- **Проблема:** PDF/PNG/JPG-рендер требует внешний `weasyprint-windows/dist/weasyprint.exe`, которого нет ни в репозитории (gitignored), ни на машине пользователя. pip-пакет `WeasyPrint==61.2` объявлен в зависимостях, но никогда не импортируется. На чистом клоне рендер падает с `FileNotFoundError`, а `build.py` падает при попытке `--add-data` несуществующей папки.
- **Решение (выбрано пользователем):** резолвер движка с цепочкой fallback: `weasyprint.exe` (если есть) → pip-пакет `python -m weasyprint` (если установлен) → понятная ошибка с инструкцией. Плюс вспомогательный скрипт установки и корректное поведение сборки.
- **Ожидаемый результат:** PDF-рендер работает на чистом клоне после `pip install -r requirements.txt` (+GTK), сборка не падает, ошибки понятны.

## 4. 🛡️ Риски, сайд-эффекты и план отката
- **Риски:** на машине без GTK `import weasyprint` кинет ImportError — резолвер ловит только `find_spec` (нахождение пакета), а не импорт; если пакет установлен, но GTK нет — WeasyPrint сам даст понятную ошибку при запуске. Это приемлемо.
- **План отката:** `git revert <фикс-коммит>` — изменения изолированы в 4 файлах.
