## 4. 🛡️ Риски, сайд-эффекты и план отката
- **Риск: потеря/дубль метода.** Митигация: тест на 68 имён (по `window_tools` + `mixins/`) + проверка, что тест ловит потерю.
- **Риск: агрегатор перестанет быть «простым классом».** Он и не должен: `ToolMethodsMixin` — единственный миксин с базами (агрегатор). Существующий `test_mixins_are_plain_classes` проверяет **все** классы в `mixins/`, поэтому либо новые миксины остаются простыми (да), либо проверка даст ложное срабатывание — учесть.
- **Риск: циклические импорты.** Новые миксины должны использовать **ленивые импорты внутри методов** (как в исходнике) — тогда цикла `mixins ↔ dialogs` нет; агрегатор импортирует миксины на уровне модуля, что безопасно.
- **План отката:** `git revert` (перенос одним-двумя коммитами); `window_tools.py` восстанавливается из истории.
