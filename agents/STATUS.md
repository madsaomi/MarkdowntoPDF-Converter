- ⚠️ Внешние сетевые сервисы: LaTeX → CodeCogs, диаграммы → Kroki. Офлайн — битые картинки.
- ⚠️ Декоративные фичи (AI-ассистент, переводчик, Plugin Marketplace, облачные шаблоны) — локальные заглушки без ML/сети.
