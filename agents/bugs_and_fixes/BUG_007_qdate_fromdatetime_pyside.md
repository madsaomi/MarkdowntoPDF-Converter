# 🐛 Баг: `QDate.fromDateTime` в PyQt6 — календарь заметок падал при открытии

**Дата:** 2026-10-21  
**Статус:** ✅ FIXED  
**Затронутые модули:** `src/gui/calendar_view.py` (`CalendarNotesDialog._scan_folder`)

---

## Симптом → Причина

- **Симптом:** при открытии диалога «Календарь заметок» на папке, содержащей
  хотя бы один `.md`-файл, вылетал `AttributeError`:

  ```
  AttributeError: type object 'QDate' has no attribute 'fromDateTime'
    File "src/gui/calendar_view.py", line 88, in _scan_folder
      date = QDate.fromDateTime(datetime.fromtimestamp(mtime))
  ```

  То есть функция «Календарь заметок» была полностью неработоспособна:
  пустая папка открывалась, любая непустая — нет.

- **Причина:** метода `QDate.fromDateTime()` нет ни в PyQt6, ни в Qt 6
  (в PyQt5/Qt5 такого статического метода тоже не было). Разработчик,
  видимо, перенёс код из другой валлидной формулы, не проверив API.
  В PyQt6 для построения `QDate` из `datetime` есть конструктор
  `QDate(datetime.date())` либо `QDate(year, month, day)`.

- **Как обнаружено:** при написании поведенческих тестов на
  `src/gui/calendar_view.py` первый же тест (создание диалога на папке с
  двумя `.md`-файлами) упал. Ранее модуль не был покрыт тестами, а
  GUI-smoke его не открывает.

## Исправление

```python
# было
date = QDate.fromDateTime(datetime.fromtimestamp(mtime))

# стало
date = QDate(datetime.fromtimestamp(mtime).date())
```

Проверено: `QDate(datetime(2026, 1, 2).date())` → `QDate(2026, 1, 2)`.
Других обращений к `QDate.fromDateTime` в проекте нет (поиск по `src/`).

## Проверка

- Новый `tests/test_calendar_view.py` (8 проверок) — зелёный:
  сканирование папки, группировка по датам, выбор даты, заглушка «нет
  заметок», предпросмотр, обрезка длинного текста, отсутствующий файл.
- Полная батарея — зелёная.

## Уроки

- Статические методы, которых нет в API фреймворка, ловятся только
  исполнением: даже «простая» утилита может быть полностью нерабочей.
- Модули, открываемые только из меню, не покрываются GUI-smoke — нужны
  отдельные поведенческие тесты.
