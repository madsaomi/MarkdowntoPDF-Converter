## Симптомы → Причины → Решения

### Неверная нарезка слайдов в `export_reveal_js`
- **Симптом:** документ с двумя заголовками (`<h1>A</h1><p>a</p><h2>B</h2><p>b</p>`) давал **3** слайда вместо 2, причём последние два были повреждены:
  - `<section><h<p>a</p>>2</h<p>a</p>>\nB\n</section>` — теги перемешаны,
  - `<section><hB>b</hB>\n\n</section>` — пустое тело и мусорный заголовок.
- **Причина:** `re.split(r'<h([12])[^>]*>(.*?)</h\1>', ...)` с одной группой захвата возвращает нечётный/чётный массив вида
  `[до, level, heading, body, level, heading, body, ...]`. Цикл же шагал с шагом **2** (`range(1, len(parts), 2)`),
  то есть после первой тройки попадал не на `level`, а на `heading`/`body` — отсюда сдвиг индексов и мусорные `<h...>`.
- **Решение:** шаг изменён на **3** (`range(1, len(parts) - 1, 3)`), что соответствует реальной раскладке парсера:
  `i → level`, `i+1 → heading`, `i+2 → body`. Граница `len(parts) - 1` гарантирует наличие тела.
- **Регрессионный тест:** `tests/test_reveal_exporter.py::test_slides_split_by_headings` проверяет ровно 2 корректных слайда.

## Уроки
- `re.split` с группой захвата отдаёт разделители **между** элементами: количество элементов = `1 + n * (групп + 1)`.
  При одной группе шаг обязан быть 3 (иначе индексы съезжают) — ошибку поймал только регрессионный тест.
