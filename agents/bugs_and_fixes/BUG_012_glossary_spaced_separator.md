# 🐛 Баг: генератор глоссария не видел определения вида `**Термин** — Определение`

**Дата:** 2026-10-22  
**Статус:** ✅ FIXED  
**Затронутые модули:** `src/core/glossary.py` (`extract_definitions`)

---

## Симптом → Причина

- **Симптом:** кнопка «Собрать глоссарий» (`build_glossary` в
  `gui/mixins/education.py`) для текста с определениями в естественном для
  русской типографики виде ничего не находила и показывала
  «No definitions found»:

  ```markdown
  **API** — Application Programming Interface
  **CLI** — Command Line Interface
  ```

  При этом вариант без пробелов (`**API**: Application Programming Interface`)
  работал.

- **Причина:** в регулярном выражении разделитель должен был идти **вплотную**
  к закрывающим звёздочкам:

  ```python
  re.compile(r'^\*\*(.+?)\*\*[:\-—]\s*(.+)$', re.MULTILINE)
  ```

  Для `**API** — …` сразу после `**` стоит пробел, поэтому `[:\-—]` не
  совпадал. Docstring модуля при этом прямо обещает поддержку
  `- **Term** — Definition`, то есть документированное поведение
  расходилось с фактическим.

- **Как обнаружено:** тест `test_extract_definitions_colon_and_dash`
  (PLAN-013): из трёх строк распознавалась только первая.

## Исправление

```python
-        re.compile(r'^\*\*(.+?)\*\*[:\-—]\s*(.+)$', re.MULTILINE),
-        re.compile(r'^\*\*(.+?)\*\*\s*:\s*(.+)$', re.MULTILINE),
+        # Разделитель может быть отделён пробелами/табами: `**Term** — Definition`
+        # (длинное тире в русской типографике всегда с пробелами).
+        re.compile(r'^\*\*(.+?)\*\*[ \t]*[:\-—][ \t]*(.+)$', re.MULTILINE),
+        re.compile(r'^\*\*(.+?)\*\*[ \t]*:[ \t]*(.+)$', re.MULTILINE),
```

Важная деталь: вместо `\s*` используется `[ \t]*`. Если бы пробельная часть
матчила `\n`, строка

```markdown
**Term**
- пункт списка
```

превратилась бы в «определение» с текстом `пункт списка`. Тест
`test_extract_definitions_does_not_cross_newlines` фиксирует, что перенос
строки разделителем не считается.

## Правило предотвращения

- **Docstring со списком поддерживаемых шаблонов — это спецификация.**
  Каждый пункт списка должен иметь тест; иначе расхождение живёт годами.
- **Для «разделитель + пробелы» в многострочных шаблонах использовать
  `[ \t]*`, а не `\s*`** — `\s` включает `\n`, и шаблон начинает склеивать
  соседние строки.
