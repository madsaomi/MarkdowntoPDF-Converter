# 🐛 Баг: активная кнопка «Назад» на первом шаге тура и «дрожащий» цвет индикатора

**Дата:** 2026-10-21  
**Статус:** ✅ FIXED  
**Затронутые модули:** `src/gui/welcome_tour.py` (`WelcomeTourDialog.__init__`, `_update_ui`)

---

## Симптом → Причина

### 1. На первом шаге кнопка «Назад» видима, но ничего не делает

- **Симптом:** тур открывается на шаге 1 из 6, при этом кнопка
  «← Назад» показана и кликабельна. Клик не производит никакого эффекта:
  `_prev()` при `_current == 0` просто ничего не делает.

- **Причина:** состояние кнопок настраивается только в `_update_ui()`
  (`btn_prev.setVisible(self._current > 0)`), а из конструктора этот метод
  **не вызывался** — только из `_next()` и `_prev()`. Поэтому до первого
  переключения шага на экране было «исходное» состояние виджетов: все кнопки
  видимы.

  Косвенное подтверждение, что задумано именно скрытие: та же `_update_ui()`
  скрывает `btn_skip` на последнем шаге, и это работало корректно — то есть
  метод был написан правильно, но применён не сразу.

- **Как обнаружено:** тест «тур открывается на первом шаге; «Назад» скрыта»
  (PLAN-013) упал на `d.btn_prev.isVisible() is False`.

### 2. Индикатор активного шага менял оттенок после навигации

- **Симптом:** при создании активная точка красится в `#8b5cf6` (фирменный
  фиолетовый проекта), а после перехода на другой шаг и возврата — уже в
  `#8b59b6`. Разница почти незаметна глазом, но цвет «уезжал».

- **Причина:** опечатка в одной цифре внутри `_update_ui()`:

  ```python
  - color = "#8b59b6" if i == self._current else "#4a4a6a"
  + color = "#8b5cf6" if i == self._current else "#4a4a6a"
  ```

  В `__init__` (первая отрисовка точек) используется правильный `#8b5cf6`,
  поэтому начальное состояние отличалось от последующих.

## Исправление

```python
         self._current = 0
+        self._update_ui()
 
     def _update_ui(self):
         self.stack.setCurrentIndex(self._current)
         for i, dot in enumerate(self.dots):
-            color = "#8b59b6" if i == self._current else "#4a4a6a"
+            color = "#8b5cf6" if i == self._current else "#4a4a6a"
```

Вызов `_update_ui()` в конце `__init__` выставляет ровно то состояние, которое
задумано дизайном: шаг 1, «Назад» скрыта, «Пропустить» видна, активная точка
нужного цвета. Повторный вызов идемпотентен, поэтому поведение после
навигации не изменилось.

## Правило предотвращения

- **Виджет, состояние которого задаётся отдельным методом `_update_*`,
  должен получить этот вызов в конструкторе.** Иначе исходный вид зависит от
  порядка создания виджетов, а не от задуманного состояния.
- **Тесты видимости дочерних виджетов требуют показанного окна:**
  `isVisible()` у ребёнка скрытого диалога всегда `False`. В тестах используем
  `d.show()` + `app.processEvents()` (offscreen), иначе проверка ничего не
  доказывает.
- **Цвета и другие «магические» константы, повторяющиеся в двух местах,
  должны сравниваться тестом между собой** — тогда опечатка в одной копии
  ловится сразу.
